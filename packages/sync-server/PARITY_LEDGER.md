# Sync Server File-Level Parity Ledger

Audit date: 2026-08-04. Paths are relative to `packages/sync-server/`.

## Scope and rules

This ledger covers all 148 hand-authored TypeScript and JavaScript files under
`src/`. It also includes the eight hand-authored JavaScript migrations in
`migrations/` because migrations were explicitly requested and are part of the
compatibility boundary, although they are stored beside rather than below
`src/`. Build output, generated protobuf output, and package/build configuration
files are excluded.
The `src/crdt-golden.test.ts`, `src/password-golden.test.ts`,
`src/historical-sqlite-golden.test.ts`, `src/db.test.js`, and
`src/app-sync/errors.test.js` verification artifacts were added after the
156-file source baseline. They are evidence for existing rows, not new source
rows to port.

`COMPLETE` requires implemented behavior, relevant Rust unit parity, shared
contract parity, and the two independent adversarial reviews required by
`RUST_PORT_GOAL.md`. `PARTIAL` means real Rust behavior exists but at least one
of those proofs is incomplete. `MISSING` means no real Rust equivalent exists.
Type-only files are still rows because they encode provider/API invariants.

The current Rust crate is green: `cargo test --manifest-path
packages/sync-server/Cargo.toml --all-targets` passes 252/252 tests, including
historical migration/SQLite, CLI, account/auth, provider, sync/file, shell, and
bank-fixture tests. The full TypeScript suite passes 605/605 tests. The latest
Pluggy and sync differential matrices pass 12/12 and 9/9 respectively against
both runtimes. Password, CORS, Akahu, and CRDT golden/differential evidence is
also green. Review status below remains conservative for every active or
finding-bearing review. Passing tests alone does not make a row complete.
